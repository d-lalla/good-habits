# Fewer sugary drinks

Swap a sugary drink for water, sparkling water or an unsweetened drink.

## Why it helps
Sweet drinks are easy to have without noticing. Counting swaps keeps the habit about what the user
chooses, not about what they avoid. The number is an example; one swap a day is a meaningful start.

## Start small
- Ask which sugary drink is the most frequent and when; start with that moment.
- Have the alternative ready (a bottle of water, a favourite tea).
- A smaller size or a diluted version also counts as a swap, if the user wants.

## How to log
- One log per swap. No value.
- Never log or comment on the sugary drinks the user did have.

## Messages
Fill the numbers from `today`.
- start: "One swap is today's example: water or something unsweetened instead of a sugary drink."
- midway: "{value} of {target} swaps today."
- almost there: "{remaining} more swap for today's {target}."
